# 测试项 · 字幕层（subtitle）

| 栏 | 内容 |
|---|---|
| **测试项名** | 字幕层：包外层、全局样式块、文本解码、解析器与公开门面 |
| **测什么** | 包外层的判序与平移；全局样式块的定界 / 位与长度对脸 / 在场与采纳；整包 UTF-8 与 `[\` 转义解码；文档语法（块、属性、文本行）、流级单调、tick 平移与六档覆盖链；公开 C ABI 的句柄生命周期与错误码；CAL 七接口的降级面与真实文本栈（NFC / Bidi / 整形 / 覆盖 / 栅格 / 描边 / 度量 / face 选择 / 系统字体解析）；渲染器的布局、折行、滚动裁剪、颜色与描边、脏矩形。 |
| **怎么测** | 前三件吃实现层头（`src/subtitle/`），逐档造字节并手改字段；解析器件既直测内部 `Parser`，也走一遍公开 C ABI（`CLV_SubtitleParserOpen/Feed/BlockAt/LineAt/Stats/Close`），确认门面只做转换；CAL 件对降级档与真实档各开一个句柄，真件用仓库内 `assets/fonts` 三份字体（CJK / 阿拉伯 / 彩色 emoji），系统侧取本机 `Segoe UI`；渲染器走公开两面：解析器取块与行，渲染器 `Layout → Render → DirtyRects`。 |
| **测哪里** | `tests/win32/subtitle/`（6 件：`test_subtitle_packet` 4 / `test_subtitle_style` 3 / `test_subtitle_text` 3 / `test_subtitle_parser` 5 / `test_subtitle_cal` 3 / `test_subtitle_render` 4，相加 = 22；另有 `header_probe_c11.c` 与 `header_probe_cxx17.cpp` 两个编译期探针，不注册用例）。 |
| **判据** | 包外层：往返 + 按容器 pts 平移、定长头不全 / 尾随 / flags 高位 / end ≤ start / 对齐枚举越界各返 `PACKET_HEADER_BAD`、超上限返 `PACKET_TOO_LARGE`、容量不足报所需长度。样式块：五位采纳与线上位序（R 落低 8 位）、位为 0 的字段照读不采纳、`bit0` 与长度两向对脸、65 515 / 65 516 边界、版本 / flags 高位 / 单位 / 保留位 / 尾随 / 字族非 UTF-8 各返 `STYLE_BLOCK_BAD`。文本：UTF-8 的 overlong / 代理区 / 截断 / 续尾档逐条判；`n` / `\\` / `emoji` 三档指令、未知指令原样、无封闭 `]` 丢到行尾、容量截断不越界。解析器：块与行视图、时间窗（ms → ticks）、六档链逐字段来源、ID 回退与 start 序违规、缺 time 与 end = start、负 tick 不判错不丢、平移越界丢块计数、Reset 后首块无条件作新基准、样式块只对此后闭合的块生效。 |
| **平台** | Win32 实测；Linux / macOS 暂无用例。CAL 的系统字体解析走 DirectWrite，非 Windows 平台工厂回 nullptr、各口回 `UNSUPPORTED`。 |
| **现状** | 通过（22 例）。渲染器默认编入（`CLV_BUILD_SUBTITLE_RENDERER=ON`），能力位 bit4 = 1；关掉该开关时各渲染口返 `CLV_SUBTITLE_UNSUPPORTED`、bit4 = 0。 |
