# 测试项 · 独立验证层（independent）

| 栏 | 内容 |
|---|---|
| **测试项名** | 独立层：梯子 + 反向对照，期望值不取自被测实现 |
| **测什么** | 容器 / 音频 / 视频 / 运动四面的边界档位（界下 / 界上 / 越界）与反向对照——用独立推导的期望验证实现，而非拿实现输出当期望。核心防的是「实现自证」。 |
| **怎么测** | 两面混吃（公开 ABI + 实现层头），但期望值来源限定白名单：公开头契约文字 + 实现层声明域常量 + 件注释内算式。口径「界下断对 / 界上断对或拒 / 越界断拒」。可单跑 `ctest -R Independent`。 |
| **测哪里** | `tests/win32/independent/`（`test_ind_container` / `test_ind_audio` / `test_ind_video` / `test_ind_video_motion`）。素材复用 video fixtures（经 `../video/test_config_expect.h` 取本档那份载体，两档数组由生成件都发）。 |
| **判据** | 崩溃 / 挂起 / 静默错位即停手。梯子 13 档 + 反向对照 8 档 = 21 例。系数级分辨力那条（`MutatedCarrierByteDiffersFromFrozen`）两档各钉一次「改一档必变」：法 1 落在第三字节 0xAE → 0xB2，定长档落在第二字节 0x00 → 0x80（9 bit 组 MSB 先出，改的是幅值末位）—— 换的是法，不是分辨力。 |
| **平台** | Win32 实测；Linux / macOS 暂无用例。 |
| **现状** | 通过（21 例）。 |
