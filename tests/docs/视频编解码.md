# 测试项 · 视频编解码面（video）

| 栏 | 内容 |
|---|---|
| **测试项名** | 视频面：VOP 头 / 宏块 / 块载体 / 载荷 / 运动 / 变换量化 / 域边界 / 无损往返 / 画质 |
| **测什么** | 视频层从语法头到重建的全链——头与片头解析、宏块头与序列、块位宽档、载荷载体往返、运动补偿、direct 缩放、量化 / DPB、域边界、无损编解往返、画质基准。 |
| **怎么测** | 句柄端到端走公开 `CLV_Video*` ABI；单元级直测走 `src/video/*.h` + `encoder_hook.h`（内部重建钩子，逐字节比对编码器内部重建 vs 解码输出）。判据 1–4 直跑可执行取 stdout。 |
| **测哪里** | `tests/win32/video/`（15 个用例 TU，另有判据分档头 `test_config_expect.h` —— 它不是 TU，不计入例数）+ `tests/win32/api/test_video_tool_rejection.cpp`、`test_video_lossless_container.cpp`。素材 `video_payload_fixtures_p.h`、`video_quant_fixtures_p.h`（冻结载体字节 / 位图 / 位宽表；载体件由 `scripts/gen_video_payload_fixtures.py` **两档都发**（生成件，不手改），后缀 F0 = 定长档 / F1 = 法 1 档。测试树里的按构型选档只落 `test_config_expect.h` 一处 `#if CLV_COEF_CODING`，库侧另两处编译期缺省兜底不参与选期望，见 `门禁.md` 的构型感知格）。 |
| **判据** | 判据 1–4：① 编解逐字节全等 2304 点 ② 重建≠源 1388/2304 点、总绝对差 2215 ③ 误差单调 q=8/32/96 → 1222<5898<11361、相等点 1279>256>173 ④ 语法往返独立成立。平块压线 256 档不等档数 0。真位移端到端 6144 点全等。满档 65535 片、25165440 点全等，载荷钉**不大于**定长档闭式 29 277 643 B（定长档这个图样恰等于自己的闭式 —— 零照样占位、没得省，那是正确结果不是回归；法 1 载体会更短，`≤` 与 `<` 对它等价）。块位宽七档表。系数载体有两种写法：定长档与法 1 档（先写结束标志 EOB，再用位数递增的 Exp-Golomb 编码写幅值）；具体用哪一档由视频帧头第 5 到第 7 位声明，本库默认法 1。两档各测：往返全等、上界按法算、全零在场块按法分岔、eob 位必须非零、跳过 MB 只接受 0 字节、手写 EG 码字按定义式解回。QF 越窗 1366>1365。`kMaxReconstructPixels = 1<<28`。画质三档 + 48 帧合成序列的九档对照值 + 分档浮动判据。拒解态与帧归还（`VideoRejectedState` 4 例 / `VideoFrameHandout` 2 例）：致命声明档三处（位深非 8；`vlc_table_id` / `alpha_enabled` / `obmc_disable` / `layer_id` 呈 v1 不收的形状；声明了工具清单却不给清单内容）打开即带拒解态而句柄不为 NULL，拒解态下除重置、关闭、观测口自身外每个入口返 `CLV_VIDEO_STREAM_REJECTED`，重置是该态唯一出口。取帧口交出帧时引用计数加一、`CLV_VideoFrameFree` 减一、计数归零才回收进空闲池；重复归还与重置之后再归还都返 `CLV_VIDEO_INVALID_ARGUMENT` 且不动计数，作废帧上 `CLV_VideoFrameGetDesc` 同码且不写出参、`CLV_VideoFrameAddRef` 返 0，句柄照常出下一支帧。 |
| **平台** | Win32 实测；Linux / macOS 暂无用例。 |
| **现状** | 通过（video 142 例，另有 api 面 `test_video_tool_rejection.cpp` 4 例、`test_video_lossless_container.cpp` 1 例）。真素材档一律跳过而非硬失败：`VideoQualityRealMedia.*` 在没有 `CLV_TEST_YUV` / `CLV_TEST_YUV_DIM`、素材打不开、维度不是 16 对齐的「宽x高」或读不足一帧时 `GTEST_SKIP`（ctest 计通过）；`VideoQuality` 两例由件内构造的编码载荷驱动、不吃外部素材，照常跑。 |
