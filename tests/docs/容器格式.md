# 测试项 · 容器格式面（container）

| 栏 | 内容 |
|---|---|
| **测试项名** | 容器格式面：`.clv` 线上布局 / 读写 / 分片 / 索引 / 扩展链 / 分段器 |
| **测什么** | 容器层的字节级格式契约——包头包体布局、帧分片写读、索引条目、扩展块链、时间基换算，以及三份入库 fixture 的端到端读回；分段器一侧钉段描述块的编解码与值域、写方的文件级链与 `flags` bit3、多段清单的自动续读、两个分段专属码的产生点、段观测计数、`CLV_WriteParams` 尺寸三档并存。两面混吃：结构编解码走实现层，句柄端到端走公开 C ABI。 |
| **怎么测** | 端到端用 `CLV_ContainerWriter*` / `Reader*` 公开面写读；单元用 `src/container/structure.h`、`io.h` 直测；fixture 件读回后与冻结表逐字节 / 逐 CRC 对账。 |
| **测哪里** | `tests/win32/container/`（`test_container_io` / `test_write_chunks` / `test_packet_frames` / `test_fixture_files` / `test_container_extchain_timebase` / `test_segments`）。素材 `assets/fixtures/` 三份 `.clv`（minimal / neg_dts / subtitle_ext4）。 |
| **判据** | fixture 冻结表（v2 的分段字段与视频参数块都在格式内；三份素材各自带 `ext_type = 3` 参数块；三份都是库内件，登记见 `assets/fixtures/provenance.txt`）：minimal 377 B / CRC `17655092` / 哈希 `2bcdff83afd6f8d1`；neg_dts 1123 / `C07BC799` / `36107e6d4e9d3690`；subtitle_ext4 1776 / `D0AB5526` / `364399556f2ecd1f`。统计必须在全程取帧之后读。分片写口 `CLV_ContainerWriterWriteFrameChunks` 13 例 = 6 条正路 + 7 条拒绝档：正路 = 单片即一帧一包、多片按数组序一包一片、同帧各片带同一 `dts_delta`、读回逐字节拼合、一次坏递交不影响已写成的帧、与 `WriteFrame` 交错写同一文件；拒绝档 = 任一片 size 为 0、任一片 data 为 NULL、片数为 0、片数组为 NULL 而片数非 0、单片越出该流 `max_packet_size`、片 `flags` bit1-7 非 0、一帧声明合计越出单帧上界 2^30。两类都在落盘之前判完，出错时一片都不写。时间基 `1081080000`。subtitle_ext4 期望读出序为 流0/1000→流1/30→流1/20→流0/200（不做排序归一）。 分段侧：段描述块载荷 48 B、整块 70 B，reserved 段与 `seg_flags` bit3-7 非 0 一律不成立，`seg_total` 填 0 / bit0 与 `seg_total` 不自洽 / `end_ticks < start_ticks` 各自一档并配「不破坏就成立」的对照；文件头 `flags` bit3 与 `file_ext_offset` 双向钉，文件头保留位（bit4-7）取 0x10 / 0x20 / 0x40 / 0x80 四个单置位一律拒、保留位全零时 0x08（bit3 = 分段）受理（`ContainerIo.FileHeadRejectsReservedFlagBits4To7` / `FileHeadAcceptsSegmentedBit3WhenReservedBitsClear`）；`DescValuesOk` 只在分段档放开 `first_dts`；写方在后续段不平移 ⇒ 首帧 dts 必须等于该流声明的 `first_dts`，差一拍判 `kValueRange`；多段清单三档实测 = 连续 6 帧 / 关自动续接只出 2 帧 / 缺一段跳过后仍出 4 帧；描述符不一致那一段整段拒接且清单走完回报 `SEGMENT_MISMATCH`，段号错位回报 `SEGMENT_ORDER` 且帧一帧不少；`WriteParams` 的 0 / 16 / `sizeof` 三档受理、其余拒，且只按 16 字节读到的尾部不得产出自称分段的文件。扩展块一致性一侧：段间参数块**内容**矛盾不拒接（返回码、帧数、`segments_mismatched` 一字不变），只经 `segments_ext_scanned` / `segments_ext_inconsistent` 成对回报；后续段**缺**块则被段身份对账整段拒接，且缺块成因计数 `video_stream_no_param_block` 与 `segments_mismatched` 同格结转（防"一格吃两因"）；主动查询口 `CLV_ContainerReaderSegExtCheck` 钉入参契约、单文件句柄与"不碰读游标"；双流与音频各自的分段矩阵格端到端闭合。 |
| **平台** | Win32 实测；Linux / macOS 暂无用例。 |
