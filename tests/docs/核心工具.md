# 测试项 · 核心工具面（core）

| 栏 | 内容 |
|---|---|
| **测试项名** | 核心工具面：varint / 带符号 varint / CRC-32 参数集 |
| **测什么** | 实现层内部工具函数的正确性——LEB128 无符号编码、zigzag 带符号编码、CRC-32/MPEG-2 校验。这些不出 C ABI，只能直测实现层。范围：编码往返、边界值、参数集锁定。 |
| **怎么测** | gtest 单元断言，直调 `src/core/varint.cpp`、`crc32.cpp` 的内部函数（经 `src/core/*.h`）。 |
| **测哪里** | `tests/win32/core/test_crc32.cpp`、`test_varint.cpp`、`test_varint_signed.cpp`。素材：无（纯算法，输入由用例构造）。 |
| **判据** | CRC-32/MPEG-2 参数集：poly `0x04C11DB7`、init 全 1、不反射输入/输出、xorout `0`（与 `src/core/crc32.h` 一致）。varint：单字节/多字节边界、终止位、值域端点逐档断编码长度与字节。 |
| **平台** | Win32 实测；Linux / macOS 暂无用例。 |
| **现状** | 通过（20 例）。 |
